Bike Sales - Excel Interactive Dashboard

An end-to-end Microsoft Excel project focused on cleaning customer demographic data, building dynamic Pivot Tables, and creating an interactive dashboard to analyze bike purchasing patterns.

Tools & Techniques Used:

Software: Microsoft Excel
Data Processing: Remove Duplicates, Nested `IF` Statements, Text Formatting
Analysis & Design: Pivot Tables, Pivot Charts, Slicers, Dashboard Design

View Repository

Key Steps & Findings

1. Data Cleaning

Removed duplicate rows, standardized values (e.g., Marital Status, Gender), and created custom Age Brackets using nested `IF` formulas.

2. Pivot Analysis

Built Pivot Tables to analyze average income per purchase, commute distance impact, and purchase habits across age groups.

3. Dynamic Dashboard

Connected Pivot Charts with interactive Slicers (Education, Region, Marital Status) for real-time data filtering.
