R Data Exploration & Visualization

A comprehensive data analysis project written in R, leveraging core libraries for data manipulation, exploratory analysis, and statistical visualization to uncover key business insights.

Technologies Used:

Language: R (RStudio)
Packages & Tools: `tidyverse`, `dplyr`, `ggplot2`, `readr`
Techniques: Data Wrangling, Group Aggregations, Statistical Charting

View Repository

Key Analysis & Steps

1. Data Cleaning

Imported datasets using `readr` and cleaned missing values, formatted data types, and filtered subsets with `dplyr`.

2. Aggregation & Metrics

Utilized pipe operators (`%>%`), `group_by()`, and `summarize()` to compute descriptive statistics and trend metrics.

3. Data Visualization

Created clear data visualizations with `ggplot2`, custom themes, and plot aesthetics to communicate findings effectively.
