Bézier Curve Visualization

Developed as my Bachelor's Thesis, this application focuses on the mathematical representation and interactive visualization of Bézier curves using Bernstein polynomials (specifically for quadratic $n=2$ and cubic $n=3$ cases). It combines concepts from Computer Graphics, Numerical Analysis, and Computational Geometry.

Technologies Used:

Language: Java
GUI Framework: Java Swing
Core Concepts: Bernstein Polynomials, Computational Geometry, Object-Oriented Programming

View Code

Key Features

Control Points Mode

Interactively set control points ($n=2, n=3$), compute Bernstein basis polynomials automatically, and render the resulting Bézier curve in real time.

Polynomial Coefficients

Supports reverse construction: input Bernstein polynomial coefficients directly to reconstruct and display the curve automatically.

Interactive Math GUI

Built with Java Swing to provide dynamic visualization of polynomial interpolation and vector-based geometric curve rendering.
