# 🌐 Personal Portfolio Website

## 📖 Overview

This repository contains my personal portfolio website, developed using **HTML**, **CSS**, and **JavaScript**.

The website showcases my background, technical skills, university and personal projects, and provides an easy way to get in touch with me.

---

## 🚀 Features

- Responsive and modern design
- About Me section
- Projects showcase
- Contact form
- GitHub and LinkedIn links
- Smooth scrolling and animations

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- ScrollReveal.js
- EmailJS
- Remix Icons

---

## 📂 Website Sections

- 🏠 Home
- 👩‍💻 About Me
- 💼 Services
- 📚 University Projects
- 🚀 Personal Projects
- 📩 Contact

---

## 🎯 Purpose

The goal of this portfolio is to present my projects, technical skills, and learning journey in Software Development, Artificial Intelligence, and Data Science.
